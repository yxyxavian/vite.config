# 骑士试炼 · Knight Trials

骑士题材的轻量 Roguelike 卡牌网页游戏。单局 5 个节点，平均 5～8 分钟，点开即玩，无需登录。

- 技术栈：Vite + TypeScript + 原生 DOM/CSS（无游戏引擎、无框架）
- 存档：`localStorage`（键名 `knight_trials_save_v1`），只保存局外记录，不做中途存档
- 部署：纯静态站点，可直接托管在 GitHub Pages

---

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 本地开发，默认 http://localhost:5173
npm run build   # 类型检查 + 生产构建，产物在 dist/
npm run preview # 本地预览构建产物
```

Node 建议 18+。

## 玩法

1. 每局沿固定路线走 5 个节点：**普通战斗 → 普通战斗 → 事件 → 精英战 → Boss 战**。
2. 每回合抽 5 张牌，拥有 3 点能量，手牌上限 7 张。
3. 护甲在你的回合开始时清空，用来抵挡敌人本回合的攻击。
4. 敌人头顶会提前显示下回合意图（攻击 / 防御 / 蓄力 / 削弱）。
5. 战斗胜利后三选一拿一张牌（可跳过）；精英战额外三选一遗物。
6. 生命归零本局结束；刷新页面视为放弃本局。
7. 金币第一版仅作记录，没有商店。

## 目录结构

```
├─ index.html
├─ vite.config.ts
├─ public/
│  └─ assets/            # 美术资源（卡面插画、敌人立绘、遗物、UI）
└─ src/
   ├─ main.ts            # 入口 + 事件委托
   ├─ styles.css
   ├─ game/
   │  ├─ types.ts        # 全局类型
   │  ├─ rng.ts          # 可替换随机源
   │  ├─ cards.ts        # 24 张卡牌（数据 + 效果）
   │  ├─ enemies.ts      # 敌人与意图
   │  ├─ relics.ts       # 遗物
   │  ├─ events.ts       # 事件
   │  ├─ map.ts          # 节点路线
   │  ├─ combat.ts       # 战斗核心（抽牌/能量/护甲/意图/胜负）
   │  ├─ state.ts        # 单局流程（路线/奖励/事件/结算）
   │  └─ save.ts         # localStorage 存档
   └─ ui/
      ├─ render.ts       # 通用组件
      └─ screens.ts      # 6 个页面
```

设计要点：
- 卡牌、敌人、遗物、事件全部是数据配置，效果写在配置的 `play()` 里，UI 不含任何游戏数值。
- 所有随机走 `src/game/rng.ts`，`setRng()` 可注入确定性序列，便于复现与测试。
- 单局状态不落盘，只有 `save.ts` 里的局外统计会写入 localStorage。

## 部署到 GitHub Pages

### 方式一：GitHub Actions 自动部署（推荐）

仓库里已包含 `.github/workflows/deploy.yml`，推送到 `main` 后自动构建并发布。

1. 在 GitHub 新建仓库，例如 `knight-trials`。
2. 推送代码：

   ```bash
   git init
   git add .
   git commit -m "feat: 骑士试炼 MVP"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/knight-trials.git
   git push -u origin main
   ```

3. 打开仓库 **Settings → Pages**，把 **Source** 设为 **GitHub Actions**。
4. 等待 Actions 跑完，访问 `https://<你的用户名>.github.io/knight-trials/`。

> `vite.config.ts` 里 `base: './'` 已使用相对路径，因此部署在 `/knight-trials/` 子路径下无需改动配置。

### 方式二：手动构建 + 发布 dist

```bash
npm run build
```

把 `dist/` 目录内容推到 `gh-pages` 分支（或用 GitHub 网页上传），再在 **Settings → Pages** 选择该分支的根目录。

### 更新游戏

重新推送 `main` 即可。域名不变的情况下，玩家本机的 `localStorage` 记录不会被清除。
